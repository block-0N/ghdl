Features

为什么用它

⚡

8 线程并发

单连接被限速到 30 KB/s 时，多连接能把总带宽跑满。实测比单线程快 10 到 200 倍。

🔄

断点续传

分片文件的大小就是进度。中断、崩溃、关窗之后重跑同一条命令，从断点继续。

🛡️

链接过期自动恢复

GitHub 的临时下载链接几十分钟就失效。收到 403 时自动重新解析，从断点接着下。

📦

三种下载对象

Actions Artifact、整个 Workflow Run 的全部产物、Release 附件，一条命令全覆盖。

🌐

代理支持

支持 --proxy 参数，也读取 HTTPS_PROXY 环境变量。有代理时自动走代理。

🔑

灵活认证

按优先级依次尝试 --token 参数、GITHUB_TOKEN 环境变量、本机 gh 命令。

Usage

三条命令

下载单个 Actions Artifact
# 先查 artifact id
gh api repos/owner/repo/actions/artifacts --jq '.artifacts[] | {id, name}'

# 下载
ghdl owner/repo <artifact_id>
下载某个 Run 下的全部产物
ghdl run owner/repo <run_id>
下载 Release 附件
# 不写文件名，列出所有附件
ghdl release owner/repo <tag>

# 写文件名，支持模糊匹配
ghdl release owner/repo <tag> windows
可选参数
--token <token> # 指定 GitHub Token
--proxy <url> # 指定代理，如 http://127.0.0.1:7890
